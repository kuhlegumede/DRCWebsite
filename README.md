Full stack school website built using React+Vite and Asp.NetCore Web Api, SDK 8.

FrontEnd Dependencies
----------------------
Tailwind.css
React-Router-Dom
In cmd type npm install, & npm run dev to run application.

Backend Dependencies
---------------------
In NUGET Packages, install EntityFrameworkCore, EntityFrameworkCore.Design, EntityFrameworkCore.Tools. EntityFrameworkCore.SQL ->
Also install MlKit (Mail Kit).
A relational database is used to store events.

In development, connect the backEnd to the frontEnd via API.
